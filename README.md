# 📖 Descripción del Proyecto

**Not-Balatro** es un videojuego inspirado en *Balatro*, desarrollado como una versión simplificada enfocada en mecánicas de poker, puntuación estratégica y modificadores dinámicos mediante jokers.

El jugador debe formar manos de poker utilizando cartas aleatorias para alcanzar un puntaje objetivo en cada ronda. A medida que el juego avanza, la dificultad incrementa y el jugador puede utilizar jokers especiales para modificar su estrategia y maximizar su puntaje.

El proyecto fue desarrollado utilizando tecnologías web modernas como React, Vite, Node.js y Express.

---

# 🎨 Temática y Estilo Visual

El juego utiliza una estética visual inspirada en:

* Pixel Art
* Videojuegos retro de 8 bits
* Temática espacial y galáctica
* Colores neon y contrastes oscuros

La interfaz busca transmitir una experiencia arcade retro con elementos visuales futuristas y espaciales.

# 🖥️ Pantallas del Juego

El proyecto cuenta con las siguientes pantallas principales:

## 🎮 Menú Principal

Pantalla inicial donde el jugador puede:

* Iniciar una partida
* Consultar reglas
* Ver puntuaciones

---

## 🃏 Pantalla de Rondas

Pantalla principal del juego donde:

* Se muestran las cartas disponibles
* El jugador selecciona su mano
* Se calcula el puntaje
* Se visualiza el score objetivo

---

## 🛒 Tienda de Jokers

Pantalla mostrada después de completar una ronda exitosamente.

Aquí el jugador puede:

* Elegir entre diferentes jokers
* Modificar su estrategia para la siguiente ronda

---

## 🏆 Pantalla de Puntajes

Pantalla que muestra:

* Puntaje actual
* Score objetivo
* Resultados de rondas anteriores
